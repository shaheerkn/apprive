# Property Content Manager Quick Reference

**Last Updated**: 2026-01-27
**Version**: 1.0
**Estimated Time to Complete**: 10-15 minutes per property

---

## Quick Start: Adding a New Property

1. Go to **Properties > Add New** in WordPress admin
2. Enter the property title (e.g., "Chalet L'Étoile")
3. Fill in the 5 tabs with property information
4. Add property description using the main content editor
5. Click **Publish**

---

## Tab 1: Basic Information

### Required Fields (marked with red asterisk *)

**Location Display Name** *
Short descriptive location (shown on property page)
Example: `Courchevel 1850, Bellecôte`

**Destination/Location** *
Select from dropdown (used for breadcrumbs and filtering)
Example: `Courchevel`

**Maximum Guests** *
Number of people the property sleeps
Example: `10`

**Bedrooms** *
Number of bedrooms
Example: `5`

**Bathrooms** *
Number of bathrooms
Example: `6`

### Optional Fields

**Size (square meters)**
Total property size
Example: `450`

**Access Type**
How guests access the property
Example: `Ski-in/Ski-out` or `5-minute walk to lifts`

**Staff Availability**
Staff services information
Example: `Full-time concierge included` or `Available on request`

---

## Tab 2: Pricing & Booking

### Required Fields

**Starting Price** *
Lowest price for the property
Example: `3500`

**Currency Symbol**
Default: `€` (can be changed to `$`, `£`, etc.)

**Price Period**
Default: `/week` (can be changed to `/night`, `/month`, etc.)

### Optional Fields

**Enquire Link**
URL for booking/enquiry page
Leave empty if not using

**Book Now Link**
URL for direct booking
Leave empty if not using

---

## Tab 3: Gallery & Media

### Required Fields

**Main Gallery** *
Upload 5-10 high-quality property images (minimum 1 required)
- Drag to reorder (first image = hero image)
- Recommended size: 1920x1080px or larger
- Format: JPG or PNG

### Optional: Seasonal Galleries

**Use Seasonal Galleries?**
Toggle ON if you have different photos for winter and summer

**Winter Gallery** (shows Nov-Apr)
Upload winter-specific images (snow scenes, skiing, etc.)

**Summer Gallery** (shows May-Oct)
Upload summer-specific images (hiking, green landscapes, etc.)

**How Seasonal Toggle Works:**
- Visitors can toggle between winter/summer views using the switch in the header
- If seasonal toggle is OFF, only Main Gallery is used
- If seasonal toggle is ON, winter and summer galleries are used (not main gallery)
- Both galleries should have similar image counts for best experience

---

## Tab 4: Features & Amenities

### Key Features Section

Click **+ Add Row** to add each feature:

**Icon Upload**
Upload a small SVG icon representing the feature
Example: Wifi icon, fireplace icon, hot tub icon

**Feature Heading**
Short title for the feature
Example: `High-Speed Wifi` or `Outdoor Hot Tub`

**Feature Description**
1-2 sentence description
Example: `Fiber-optic connection throughout the property`

**Repeat** for all key features (typically 5-8 features)

---

### Room Details Section

Click **+ Add Row** to add each room:

**Room Name**
Room title
Example: `Master Suite` or `Living Room`

**Room Description**
Detailed description of the room (2-3 sentences)
Example: `Spacious master bedroom with king-size bed, en-suite bathroom with rain shower, and private balcony overlooking the slopes.`

**Room Images** (optional)
Upload 1-3 images specific to this room
Example: Bedroom photos, bathroom photos

**Repeat** for all rooms you want to highlight (typically 5-7 rooms)

---

## Tab 5: Services & Extras

Click **+ Add Row** to add each service:

**Service Icon**
Upload a small SVG icon representing the service
Example: Chef icon, spa icon, ski icon

**Service Heading**
Short title for the service
Example: `Private Chef` or `In-Chalet Spa`

**Service Description**
1-2 sentence description
Example: `Professional chef available for breakfast and dinner service`

**Repeat** for all services (typically 4-6 services)

---

## Main Content: About the Property

Below all the tabs, use the WordPress editor to add:

**About the Chalet/Property**
Write 2-5 paragraphs describing:
- Overall property feel and ambiance
- Location highlights and nearby attractions
- Special features or unique selling points
- Ideal guest profile (families, couples, groups, etc.)

**Formatting Tips:**
- Use headings (H2, H3) to break up long text
- Add bullet points for lists
- Keep paragraphs 3-4 sentences max
- Write in a warm, inviting tone

---

## Tips for Uploading Icons

**Where to Find Icons:**
- IconFinder (https://www.iconfinder.com/)
- Flaticon (https://www.flaticon.com/)
- Noun Project (https://thenounproject.com/)

**Icon Requirements:**
- Format: SVG (vector format)
- Color: Single color works best (ideally matches theme)
- Size: Small files (< 10KB)
- Style: Consistent across all icons (same line weight, same style)

**How to Upload:**
1. Click "Select File" or "Add Image" button
2. Upload from Media Library or drag-drop SVG file
3. If SVG upload is blocked, contact your developer

---

## Common Mistakes to Avoid

❌ **Uploading very large images**
✅ Resize images to max 2000px width before uploading

❌ **Using inconsistent icon styles**
✅ Use icons from the same icon set for visual consistency

❌ **Writing very long feature descriptions**
✅ Keep feature descriptions to 1-2 sentences max

❌ **Forgetting to fill required fields**
✅ Look for red asterisks (*) - these fields are mandatory

❌ **Not testing seasonal galleries**
✅ After publishing, view the property and test the winter/summer toggle

❌ **Using low-quality images**
✅ Use professional photography, min 1920px wide

---

## Checklist Before Publishing

- [ ] Property title is clear and descriptive
- [ ] All required fields (*) are filled
- [ ] Main gallery has at least 5 high-quality images
- [ ] Gallery images are ordered correctly (best image first)
- [ ] If using seasonal galleries, both winter and summer have images
- [ ] All key features have icons and descriptions
- [ ] Room details are complete with descriptions
- [ ] Services are listed with icons and descriptions
- [ ] About the Property content is written and formatted
- [ ] Preview the property page before publishing
- [ ] Test the winter/summer toggle if using seasonal galleries
